## 常规局任务

按照岳明兄分析，目标系统（任务系统）已经实现，在小岛抢开始时，让玩家去自动领取一个任务（目标）即可，发奖励都是自动的，不需要管了。

领取任务方法是:
`GoalSystem->RegisterGoalDefaultHandle(PS, EGST_Achievement, Key);`



详见任务相关代码：

```cpp

void UGangstarAchievementSystem::DoInitAchievementList(const ABasePlayerState* PS) const  
{  
    if (!PS)  
    {       
	    return;  
    }    
    
    const auto TablePostProc = UTablePostProcessing::Get();  
    if (!TablePostProc)  
    {       
	    return;  
    }    
    
    if (const auto GoalSystem = UServerLogicSubsystem::GetLogic<UGangstarGoalSystem>(GetWorld()))  
    {       
	   const auto& AchievementGoalDatas = GetAllGoalData(EGST_Achievement);  
       for (const auto& Pair : AchievementGoalDatas)  
       {
          if (!PS->IsGoalCompleteOrFinished(EGST_Achievement, Pair.Key, 0, Pair.Value->TargetCount))  
          {
              GoalSystem->RegisterGoalChangeEvent(PS, EGST_Achievement, Pair.Key, GoalEventCallback, true, true);  
             //GoalSystem->RegisterGoalDefaultHandle(PS, EGST_Achievement, Pair.Key);  
          }  
          else  
          {  
             GoalSystem->RemoveSystemGoalRecorder(PS, EGST_Achievement, Pair.Key, 0, false);  
          }       
		}    
	}
}

```
